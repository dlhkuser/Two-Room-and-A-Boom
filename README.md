# 兩室一彈 玩家手冊

《Two Rooms and a Boom》的繁體中文互動手冊，用手機或電腦開啟即可。

- **規則**：遊戲目標、準備、基本規則、領袖與人質、回合結束五步驟、分享與展示
- **組牌**：選擇人數（6–30 人），顯示回合數、每回合人質數與推薦牌組
- **角色**：74 個角色，可用中文、英文卡名或能力搜尋，並依隊伍篩選；點角色會標出要一起放入的角色
- **配對與狀態**：成對、連動、對應角色一覽，以及所有「狀態」的說明

支援淺色／深色模式切換。
